 **A from-scratch Mini LLM implementation exploring tokenization, embeddings, attention mechanisms, and Transformer architecture.**
## About This Project

Created by **Derrick Agorhom**, this project focuses on learning the internal mechanics of LLMs by implementing each component step-by-step rather than relying entirely on existing frameworks.

The goal is to understand how raw text is transformed into numerical representations and eventually processed through Transformer-based neural networks.
